# To-Do List App

A single-user to-do list backend, built as a learning project for Java Spring Boot. Built step by step, with each step reviewed before moving to the next — see [docs/implementation-plan.md](docs/implementation-plan.md).

## Status

🚧 In progress — steps 1–6 of the [implementation plan](docs/implementation-plan.md) done (scaffolding, DB + Flyway migration, entities, repositories, DTOs, service layer). Next: controllers.

## Tech stack

- **Java 21** / **Spring Boot 4.1.1**
- **Gradle** (build tool)
- **PostgreSQL** (database) + **Spring Data JPA**
- **Flyway** (database migrations)
- Deployment target: **Railway** (PaaS)

Full rationale for each choice: [docs/tech-stack.md](docs/tech-stack.md).
