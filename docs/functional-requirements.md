# Functional Requirements — To-Do List App

Single-user to-do list app (no accounts/login).

## Core task management

- Users should be able to create a new task with a title and optional description
- Users should be able to view a list of all their tasks
- Users should be able to edit a task's title/description
- Users should be able to delete a task
- Users should be able to mark a task as complete or incomplete
- Users should be able to view completed and incomplete tasks separately (or filter by status)

## Organization

- Users should be able to assign a due date to a task
- Users should be able to see overdue tasks highlighted or grouped separately
- Users should be able to assign a priority level (e.g. low/medium/high) to a task
- Users should be able to group tasks into lists or projects (e.g. "Work", "Personal")
- Users should be able to tag/label tasks for cross-cutting organization

## Viewing and finding tasks

- Users should be able to sort tasks (by due date, priority, or creation date)
- Users should be able to filter tasks (by status, list/project, tag, or priority)
- Users should be able to search tasks by title/description text

Scope confirmed for v1.
